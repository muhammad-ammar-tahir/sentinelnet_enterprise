## Brand & Style

This design system embodies high-assurance network intelligence, sovereign telemetry, and automated infrastructure remediation. Designed for SecOps engineers, Network Operations Center (NOC) commanders, and platform architects, the aesthetic balances uncompromising technical density with futuristic precision.

The visual direction merges **Technical Brutalism** with **Deep-Space Glassmorphism**:
- **Atmosphere:** Deep cyber surfaces create an infinite field upon which telemetry pulses and glows. Interfaces feel authoritative, clinical, and watchful.
- **Micro-Details:** Razor-thin structural borders, precise 1px grids, glowing status beacons, and high-density diagnostic data tables.
- **Emotional Intent:** Unflinching confidence, immediate threat clarity, hyper-legible telemetry during high-stress operational incidents, and the feeling of commanding an advanced digital substrate.

## Colors

The palette establishes high chromatic signal-to-noise ratios against an abyssal dark spectrum.

### Surface Tiers
- **Void (Canvas Base):** `#070B14` — Deepest canvas underpinning background network topology graphs and canvas nodes.
- **Surface Layer 1:** `#0B1120` — Default application viewport and layout scaffolds.
- **Surface Layer 2:** `#0F172A` — Cards, inspection panels, floating toolbars, and modal bases.
- **Surface Layer 3:** `#111827` — Hover states, inset data terminals, and active interactive regions.

### Chromatic Signals & Accents
- **Primary Signal (Emerald):** `#10B981` (Hover: `#059669`, Active Glow: `rgba(16, 185, 129, 0.45)`) — Represents healthy telemetry nodes, validated zero-trust routes, and primary actions.
- **Secondary Signal (Cyber Teal):** `#06B6D4` (Deep Teal: `#0891B2`) — Used for real-time autonomous agent actions, diagnostic trace lines, and dynamic telemetry throughput.
- **Critical Breach (Red):** `#EF4444` — Imminent network degradation, breach vectors, and fatal anomalies.
- **Degraded/Warning (Amber):** `#F59E0B` — High packet jitter, memory saturation, and route divergence.

### Borders & Overlays
- **Hairline Border:** `rgba(255, 255, 255, 0.08)` — Primary separator for all glass panels.
- **Active Grid Line:** `rgba(255, 255, 255, 0.03)` — Static background graph lines.

## Typography

The typographic hierarchy prioritizes rapid scannability during mission-critical events.

- **Headlines (Plus Jakarta Sans):** High modern precision, slight structural geometry to convey forward-leaning defense intelligence.
- **Body & UI Controls (Inter):** Highly neutral and legible at low pixel sizes, engineered specifically for high-information density data tables and operational sidebars.
- **Telemetry & Metadata (JetBrains Mono):** Reserved for raw IP addresses, CIDR blocks, SHA hashes, timestamps, port numbers, and metric counters. All numerical values inside analytical dashboards must use tabular figures (`font-variant-numeric: tabular-nums`).

## Layout & Spacing

The layout model is driven by operational density and flexible modular dock panels.

### Structural Grid
- **Desktop (1440px+):** Fluid 12-column grid with fixed collapsible side rails (left activity bar: 64px, navigation drawer: 240px, live inspector: 380px). 16px (`gutter`) gutters between analytical cards.
- **Tablet / Workstation Small (768px - 1439px):** 8-column layout. Analytical inspectors collapse into floating bottom drawers or side flyouts.
- **Mobile Handheld (<768px):** 4-column layout with fixed stacked panels, pinned quick-action telemetry banners, and compressed `margin-mobile` (16px).

### Spacing Philosophy
Compact micro-spacing ensures that maximum operational telemetry is visible above the fold without scrolling. Component-internal spacing defaults to `space-sm` (8px) and `space-md` (12px), creating a snug, enterprise-grade command-center feel.

## Elevation & Depth

Visual hierarchy uses luminous depth, glass layering, and chromatic edge luminescence rather than traditional dropped shadows.

### Glassmorphic Layers
- **Card Panel Base:** `background: rgba(15, 23, 42, 0.75)` overlaid on canvas, enhanced with `backdrop-filter: blur(12px)`.
- **Panel Edges:** Enclosed strictly with `1px solid rgba(255, 255, 255, 0.08)`. Top-edge light catches use `border-top: 1px solid rgba(255, 255, 255, 0.14)` to simulate subtle overhead digital illumination.
- **Floating Modals & Flyouts:** `background: rgba(11, 17, 32, 0.92)` with `backdrop-filter: blur(20px)` and shadow ring: `0 20px 40px -15px rgba(0, 0, 0, 0.7), 0 0 0 1px rgba(6, 182, 212, 0.25)`.

### Ambient Glows
- **Telemetry Pulse Glow (Healthy):** `box-shadow: 0 0 12px rgba(16, 185, 129, 0.35)` on active indicators and success triggers.
- **Telemetry Pulse Glow (Alert):** `box-shadow: 0 0 14px rgba(239, 68, 68, 0.45)` for breached ports or compromised workloads.
- **Active Selection Glow:** Subtle interior highlight `box-shadow: inset 0 0 0 1px #06B6D4`.

## Shapes

The design system adopts a crisp, modern **Soft (`1`)** shape archetype. Radii are intentionally kept tight and angular to communicate technical rigor, structural durability, and architectural stability.

- **Base Radius (0.25rem / 4px):** Standard buttons, diagnostic inputs, table row highlights, and metric badges.
- **Panel Radius (`rounded-lg` - 0.5rem / 8px):** Primary telemetry cards, graph viewports, side rail containers, and contextual popovers.
- **Modal Radius (`rounded-xl` - 0.75rem / 12px):** Primary configuration modals, command palettes, and global topology inspectors.
- **Circular / Full (`9999px`):** Reserved exclusively for live network beacon status dots and avatar initials.

## Components

### Buttons
- **Primary Action (Remediate / Deploy):** Background `#10B981`, foreground `#070B14` (ultra-high contrast), font `Inter` weight 600. On hover: `#059669` with `box-shadow: 0 0 16px rgba(16, 185, 129, 0.4)`.
- **Secondary Action (Inspect / Filter):** Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.1)`, foreground `#F8FAFC`. On hover: border `rgba(6, 182, 212, 0.5)`, foreground `#06B6D4`.
- **Ghost/Tertiary:** No border, transparent background, mono typography, foreground `#94A3B8`.

### Status Indicators & Beacons
- **Pulse Indicators:** Dual-ring construction: an inner solid 6px dot surrounded by a 14px concentric ring with an infinite keyframe breathing pulse (`transform: scale()`, opacity fading from `0.6` to `0`).
- **Telemetry Badges:** Low-height (20px), monospace font (`code-sm`), padding `0 6px`. Inset background tint (e.g., `rgba(16, 185, 129, 0.1)`) with matching `1px` tinted border (`rgba(16, 185, 129, 0.25)`).

### Input Fields & Terminal Search
- **Height:** 32px (Compact/NOC density) or 40px (Default).
- **Surface:** `rgba(7, 11, 20, 0.85)` with `1px solid rgba(255, 255, 255, 0.08)`. Placeholder text in `#64748B`.
- **Focus State:** Border changes to `#06B6D4` with an ambient cyan flare: `box-shadow: 0 0 0 1px #06B6D4, 0 0 10px rgba(6, 182, 212, 0.2)`.

### Telemetry Cards & Metric Panels
- **Structure:** Encased in glass surface `#0F172A` (75% opacity), top edge-highlighted border.
- **Header:** Uppercase metadata header (`label-sm`), trailing live throughput icon or delta trend arrow (+0.04% in `#10B981`).
- **Inner Division:** Sub-metrics divided by hairline borders `rgba(255, 255, 255, 0.04)`.

### Checkboxes & Toggle Switches
- **Checkboxes:** 14px x 14px square, radius 2px, surface `rgba(15, 23, 42, 0.9)`, border `1px solid rgba(255, 255, 255, 0.2)`. Selected state uses `#10B981` background with deep slate checkmark icon.
- **Autonomous Toggles:** Compact 28px width switch with smooth glow slide; active track triggers glowing teal `#06B6D4`.

### Autonomous Incident Feed & Command Palette
- **Incident Feed:** Left-bordered cards indicating severity level (Green 2px border for autonomous resolution, Red 2px for manual intervention needed).
- **Command Palette:** Central spotlight modal (`Cmd + K`) using dense monospaced keyboard shortcuts and instant real-time query syntax highlighting.
